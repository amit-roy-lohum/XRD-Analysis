# DARA Implementation Decisions

| Step | Decision |
|------|----------|
| Investigate `dara-xrd` API before coding | Read source of installed package (pip install dara-xrd) to discover what runs without BGMN; found `PeakMatcher`, `rpb()`, `find_residual_regions()` are pure Python; `search_phases()` and `detect_peaks()` both require BGMN/ray. |
| `PeakMatcher` not used despite being BGMN-free | `PeakMatcher` uses `scipy.spatial.distance.cdist` with a custom metric (`absolute_log_error`) that returns an array instead of a scalar; this breaks with scipy >= 1.13 (installed: 1.18.1), causing a `ValueError`. Skipped to avoid silent wrong results. |
| Three-tier scorer hierarchy | Separated BGMN (Tier 1), profile-Rwp (Tier 2), and simple peak-match (Tier 3) so the notebook degrades gracefully and the active tier is always printed to the user. |
| Tier 2: profile Rwp with pseudo-Voigt broadening | Simple Gaussian broadening ignores angle-dependent peak width; pseudo-Voigt with Caglioti FWHM (FWHM^2 = U*tan^2(theta) + V*tan(theta) + W) is the exact functional form used by BGMN and GSAS-II, making Tier-2 scores directly comparable to future Tier-1 outputs. |
| Analytical scale factor in Rwp | Used least-squares optimal scale s = sum(w*y_obs*y_calc)/sum(w*y_calc^2) to decouple absolute intensity from pattern shape; without this every phase with wrong total counts would score near zero. |
| Poisson weights in Rwp | Used w = 1/sigma^2 (counting statistics) matching the Rietveld convention; sigma is carried through from the raw data loader and updated by SNIP background propagation. |
| Also report DARA RPB when `dara-xrd` is installed | `dara.utils.rpb()` computes the background-free profile R-factor (RPB) used internally by DARA; storing it in `candidate.metadata["rpb"]` allows direct comparison when full BGMN runs become available later. |
| `score = max(0, 1 - Rwp/100)` conversion | Rwp is in percent (0-100+); this maps it linearly to [0,1] matching the convention already used by the notebook's simple scorer and expected by CP1. |
| Background for Rwp numerator/denominator | After SNIP subtraction the stored background (in `pattern.metadata["background"]`) is passed as `y_bkg` to `rpb()`; for the Rwp computation the background is already subtracted from `y_obs`, so `y_bkg` is effectively zero, which is correct. |
| Tier-1 BGMN integration uses CIF export + `search_phases()` | `dara.search_phases()` requires CIF file paths, not pymatgen Structure objects; `pymatgen.io.cif.CifWriter` handles the conversion in a temp directory. Wavelength is mapped from Angstroms to DARA's string labels (Cu/Mo/Co/Cr/Fe). |
| Tier-1 falls back to Tier-2 on any exception | BGMN integration has many failure modes (missing binary at runtime, CIF conversion errors, ray init failures); catching all exceptions and falling through to Tier-2 prevents a hard crash at CP1. |
| `broadened_pattern()` gains `use_pseudo_voigt` flag | Visualisation overlays now optionally use the same pseudo-Voigt shape as the scorer (set automatically when `_DARA_AVAILABLE`), so the overlay shown to the user matches the scoring basis. Old `sigma` Gaussian path preserved for backwards compatibility. |
| Ranking table shows Rwp% and RPB% columns dynamically | Columns are only printed if the scorer has populated the metadata fields, so the table degrades cleanly when Tier-3 is active. |
| No `.py` module files created | All code added inline to the notebook cells per the project delivery rules in CLAUDE.md. |
| `dara-xrd` pip-installed to inspect source | Package was listed as a dependency in the notebook header but was not installed; installed it to read the actual API rather than relying on PyPI docs alone. |
| `_DARA_AVAILABLE` probe imports only `dara.utils`, not `dara.search.peak_matcher` | `peak_matcher` was previously included in the probe import; it has a runtime-crashing scipy >= 1.13 incompatibility that could trigger at import time in future versions, silently disabling Tier 2; removed it since it is never used. |
| numpy pinned to `<2` + bottleneck force-reinstalled in automated_refinement.ipynb | dara-xrd and its transitive deps (bottleneck, scikit-learn) are compiled against NumPy 1.x; NumPy 2.x breaks binary ABI compatibility causing ImportError at import time; downgrade + force-reinstall rebuilds bottleneck against the pinned version. |
| `mp_api.client` import deferred to fallback branch in automated_refinement.ipynb | `mp_api/client/mprester.py` has a top-level `from pymatgen.analysis.phase_diagram import PhaseDiagram` which fails when only `pymatgen-core` is installed; deferring the import to the `else` branch (only runs when notebook_01 cache is absent) avoids the error entirely on the normal path. |
| notebook_01 cache reused via PhaseCandidate stub + `__main__` injection | PhaseCandidate is defined inline in notebook_01's `__main__`; pickle stores the class reference as `__main__.PhaseCandidate`; defining an identical stub in this notebook and registering it via `__main__.PhaseCandidate = PhaseCandidate` before `pickle.load()` lets the cache unpickle correctly without re-running notebook_01. |
| XRD file copied to `.cache/pattern_nmc.xy` before passing to BGMN | BGMN fails silently on file paths containing spaces or parentheses; the source file `M8303-SC(B-3) 1411025_exported.xy` has both; copying to a clean name guarantees reliable BGMN execution. |
| `WAVELENGTH_NM = WAVELENGTH_A / 10` passed to every `do_refinement_no_saving` call | DARA accepts numeric wavelengths in nm, not Å; omitting the wavelength arg would default to Cu Kα (0.15406 nm ≈ 1.5406 Å), which is wrong for this sample's 1.56 Å source and would shift all Bragg positions by ~0.01 Å. |
| `lattice_range=0.03` for NMC rather than tutorial's 0.05 | NMC layered-oxide lattice parameters are well-known (a ≈ 0.284 nm, c ≈ 1.42 nm); a tight ±3% window prevents BGMN from drifting into unphysical solutions while still accommodating real compositional variation across the Li-Ni-Mn-Co-O system. |
| Phase name lookup made dynamic in results cells | Tutorial hardcoded `"CaNi(PO3)4_15_sym"`; NMC phase names are generated by BGMN from the CIF filenames (mp-XXXXXX.cif → `mp-XXXXXX_SG_sym`) and are not known in advance; `list(refinement.lst_data.phases_results.keys())[0]` works for any refinement output. |
